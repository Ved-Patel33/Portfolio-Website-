# Ved Patel - Portfolio Website

A personal portfolio website showcasing my engineering projects, experience, and skills. Built with vanilla HTML, CSS, and JavaScript, focusing on a clean, responsive, and performance-oriented design.

## Features

- **Responsive Design**: Fully responsive layout that adapts to all device sizes.
- **Interactive UI**: Smooth scrolling, animations, and dynamic elements.
- **Project Showcase**: Detailed cards for projects with hover effects.
- **Experience Timeline**: Visual timeline of professional experience.
- **Contact Form**: Integrated contact form with validation.

## Tech Stack

- **HTML5**: Semantic structure.
- **CSS3**: Custom styling with variables, flexbox, and grid (No frameworks).
- **JavaScript (ES6+)**: DOM manipulation, intersection observers, and interactive logic.

## Setup & Deployment

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Ved-Patel33/Portfolio-Website-.git
   ```
2. Open `index.html` in your browser.

For deployment instructions, please refer to [DEPLOYMENT.md](DEPLOYMENT.md).

## Project Structure

- `index.html`: Main structure of the portfolio.
- `styles.css`: Global styles and responsive design.
- `script.js`: Interactive functionality and animations.
- `assets/`: Images and other static assets.
